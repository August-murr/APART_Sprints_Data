Abstract  
The  project  presents  an  AI  Governance  Challenge  Framework  utilizing  Trusted  Execution  Environments  (TEEs)  to  address  the  critical  problem  of  proving  a  dataset's  safety  without  revealing  the  private  data  itself.  The  core  approach  involves  a  protocol  where  a  Data  Provider,  holding  a  private  dataset,  executes  a  Challenger's  detection  script  (packaged  as  a  WebAssembly  module)  inside  a  TEE.  This  process  generates  a  cryptographically  signed  attestation  package,  which  proves  the  script  was  run  correctly  over  the  full  dataset.  A  Judge  component  (LLM-powered)  veriﬁes  this  attestation  and  examines  any  ﬂagged  documents  for  unsafe  content.  The  hackathon  demo  is  deployed  on  a  cloud-based  server  utilizing  real  TEE  hardware,  establishing  a  veriﬁable  mechanism  for  dataset  safety  assurance.
