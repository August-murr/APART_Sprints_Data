Abstract
We present Markov Chain Lock (MCL) watermarking, a cryptographically secure framework for
authenticating LLM outputs. MCL constrains token generation to follow a secret Markov chain over
SHA-256 vocabulary partitions. Using doubly stochastic transition matrices, we prove four theo-
retical guarantees: (1) exponentially decaying false positive rates via Hoeffding bounds, (2) grace-
ful degradation under adversarial modification with closed-form expected scores, (3) information-
theoretic security without key access, and (4) bounded quality loss via KL divergence. Experi-
ments on 173 Wikipedia prompts using Llama-3.2-3B demonstrate that the optimal 7-state soft
cycle configuration achieves 100% detection, 0% FPR, and perplexity 4.20. Robustness test-
ing confirms detection above 96% even with 30% word replacement. The framework enables
O(n) model-free detection, addressing EU AI Act Article 50 requirements. Code available at
https://github.com/ChenghengLi/MCLW.
1. Introduction
The EU AI Act Article 50 [1] mandates machine-readable marking of AI-generated content, with
enforcement beginning August 2026. Current approaches partition into passive detection [2, 3]
and active watermarking [4]. Passive methods suffer high false positive rates and paraphrasing
vulnerability [5]; active schemes degrade under token substitution and require probabilistic sampling
incompatible with greedy decoding.
We introduceMarkov Chain Lock (MCL) watermarking, constraining token generation
to follow a secret finite-state Markov chain over cryptographic vocabulary partitions. Using doubly
stochastic transition matrices (e.g., clockwork:i→(i+ 1) modS, or soft cycle:i→ {i+ 1, i+ 2}),
we create detectable state patterns verifiable only with the secret key (Figure 1).
Contributions.(1) Complete mathematical framework with cryptographic state assignment and
clockwork topology; (2) four theorems establishing exponential false positive decay (Theorem 4.1),
robustness bounds (Theorem 4.3), information-theoretic security (Theorem 4.4), and quality preser-
vation (Theorem 4.5); (3) empirical validation on 173 Wikipedia concepts across 28 configurations;
(4) practical algorithms forO(N(V+T LM)) embedding andO(n) model-free detection.

2. Related Work
Passive detection methods analyze statistical properties of generated text: DetectGPT [2] examines
log-probability curvature, while GPTZero [3] combines perplexity and burstiness metrics. However,
these approaches suffer high false positive rates on technical writing and fail under paraphras-
ing [5, 6]. Active watermarking embeds verifiable signals during generation. Kirchenbauer et al. [4]
partition vocabulary into green/red lists via keyed hashing, but this degrades under paraphras-
ing and requires temperature sampling. Aaronson [7] proposes semantic-level embedding requiring
expensive model queries, while Christ et al. [8] establish fundamental quality-security tradeoffs.
Chen et al. [9] propose Pattern-Mark, a Markov-chain-based watermarking framework for order-
agnostic language models using probabilistic transitions and pattern-frequency detection. MCL
targets autoregressive LLMs with deterministic transitions, enabling greedy decoding compatibility
and model-free O(n) detection via transition validity verification.
MCL advances prior work through: (1) deterministic embedding compatible with greedy de-
coding; (2) model-freeO(n) detection; (3) provable exponentially small FPR via Hoeffding bounds;
and (4) explicit quality-security parameterization through tunable overlapρ.

3.4 Soft Partitions
Hard partitions restrict each token to exactly one state, which may limit vocabulary choices and
degrade generation quality. Soft partitions allow controlled overlap between states.
Definition 3.8(Soft State Membership).Given overlap ratioρ∈[0,1], the soft membership

5. Experimental Design
To empirically validate our theoretical framework, we conduct comprehensive experiments across
diverse textual domains and watermarking configurations. This section details the dataset con-
struction, text generation methodology, and evaluation criteria.
5.1 Dataset Construction
We construct an evaluation corpus comprising 173 concepts selected from the most frequently
accessed Wikipedia articles, ensuring both topical diversity and practical relevance. The corpus
systematically spans six semantic categories:notable figures(e.g., Albert Einstein, William Shake-
speare, Elon Musk),historical events(e.g., World War II, French Revolution, the Renaissance),
scientific phenomena(e.g., quantum mechanics, DNA replication, black holes),geographical entities
(e.g., Mount Everest, Amazon River, Antarctica),technological concepts(e.g., artificial intelligence,
cryptocurrency, neural networks), andcultural references(e.g., Star Wars, Harry Potter, Game of
Thrones).
For each conceptc, we construct a standardized promptp c of the form:“Explain [concept] in
a comprehensive way.”This formulation elicits informative, multi-sentence responses suitable for
watermark embedding and detection analysis.

5.2 Text Generation Protocol
We generate paired samples for each concept to enable controlled comparison between watermarked
and baseline conditions:
•W atermarked generation.Text is produced using Algorithm 1 withsoft cycletransition
enforcement (Example 3.5). At each decoding step, the model’s output distribution is masked
to permit only tokens belonging to valid successor partitionsV (s+1) modS orV (s+2) modS ,
followed by sampling from the masked distribution. This procedure guaranteesϕ(t)≈1.0 for
all generated sequences.
•Baseline generation.Non-watermarked text is produced using standard nucleus sampling
with temperatureT= 0.7 and cumulative probability thresholdp= 0.9, without any vo-
cabulary constraints. These samples establish the null distribution for false positive rate
estimation.
All experiments employ Llama-3.2-3B-Instruct as the base language model, with a maximum
generation length of 200 tokens. We systematically evaluate 7×4 = 28 configurations spanning
state countsS∈ {2,4,5,7,9,11,15}and overlap ratiosρ∈ {0%,5%,10%,15%}. Reproducibility is
ensured through fixed random seed (42) and cryptographic key (curated wiki dataset 2024).
5.3 Evaluation Metrics
We quantify watermarking performance along four complementary dimensions:
•Fingerprint Scoreϕ(t)∈[0,1]: The proportion of consecutive token pairs exhibiting valid
transitions according to the transition matrix (Definition 3.7). For watermarked text using
soft cycle,ϕ≈1.0 by construction; for random text,E[ϕ] = 2/S(Theorem 4.1).
•T rue Positive Rate (TPR): The fraction of watermarked samples correctly identified,
computed as TPR =|{t w :ϕ(t w)> τ}|/|{tw}|with thresholdτ= 0.5.
•F alse Positive Rate (FPR): The fraction of non-watermarked samples erroneously classi-
fied as watermarked, representing the Type I error rate critical for deployment reliability.
•Perplexity (PPL): The exponential of cross-entropy loss, PPL = exp

Our experiments reveal four critical findings.First, configurations withS≥5 andρ= 0% achieve
perfect separability: the minimum watermarked score exceeds the maximum non-watermarked score,

with Theorem 4.5.Third, low state counts fail:S= 2 yields 100% FPR (all sequences trivially

7. Discussion
MCL watermarking addresses EU AI Act Article 50 [1] requirements for machine-readable AI
content marking. The model-free detection (Algorithm 2) enables third-party auditing without
LLM access, supporting transparency frameworks [10], while provable guarantees (Theorems 4.1 to
4.5) provide legally defensible authentication with quantifiable error rates.
Limitations.(1) Detection requires the same tokenizer used during generation; (2) at least 5
states are needed for reliable detection (S= 2 is unusable); (3) overlapρ≥10% severely degrades
detection; (4) perplexity increases with states, thoughS= 7 achieves reasonable PPL = 4.20.

F uture W ork.A promising direction issparse watermarking: introducing a “full vocabu-
lary” state that allows unrestricted token selection, watermarking only everyN-th token (e.g.,
N= 10). This preserves generation quality while maintaining theoretical guarantees, since any
doubly stochastic transition matrix ensures uniform stationary distribution. Other directions in-
clude adaptive overlap selection based on token probability mass, C2PA metadata integration for
end-to-end provenance, robustness against learned adversarial attacks, and multi-model coordi-
nation for heterogeneous deployments. Preliminary experiments on Mistral-7B and GPT-2-XL
(Appendix E) confirm consistent behavior across model architectures. We hypothesize that larger
vocabulary sizes reduce perplexity under partitioning, as each partition contains more candidate
tokens.
8. Conclusion
We established complete mathematical foundations for Markov Chain Lock watermarking us-
ing doubly stochastic transition matrices over SHA-256-based vocabulary partitions. Our theo-
retical results generalize to any irreducible doubly stochastic chain withkvalid successors per
state, providing: (1) exponentially decaying false positive rates bounded by Hoeffding’s inequal-
ity (Theorem 4.1), (2) quantified robustness under adversarial token modification with formula
E[ϕ] = (1−δ) 2 +kδ(2−δ)/S(Theorem 4.3), (3) information-theoretic security under the random
oracle model (Theorem 4.4), and (4) logarithmic quality degradation in state count (Theorem 4.5).
Experiments on 173 Wikipedia concepts across 28 configurations demonstrate that 7-state soft
cycle (k= 2) with 0% overlap is optimal, achieving 100% detection, 0% FPR, and perplexity
4.20. Robustness validation confirms detection remains above 96% even with 30% word modifica-
tion. The framework providesO(n) model-free detection, directly addressing EU AI Act Article 50
requirements.
