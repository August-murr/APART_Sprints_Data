Abstract  
Refusal  benchmarks  measure  whether  a  model  refuses  the  prompt;  when  a  frontier  model  refuses,  that  leaves  the  responder  to  fall  back  to  a  local  open  weight  mode.  That  fallback  cost  is  unmeasured.  We  built  12  forensic  tasks  from  real  recovered  payloads  of  the  Open-AI-Hugging  Face  incident.  And  ran  them  against  a  9B  model  quantized  for  a  single  8GB  consumer  grade  GPU.  Each  response  was  graded  using  a  three-state  evaluation  method  (correct,  refused,  silent  failure)  against  published  ground  truth.  The  model  refused  0/12  times,  however,  only  7  were  correct  and  usable,  while  5  were  silent  failures  that  the  current  metric  would  score  compliant  (pass).  A  refusal  metric  scores  this  run  100%  compliant  while  only  58%  was  usable.  And  doubling  the  context  window  recovered  none.  The  failures  are  a  degenerate  reasoning  loop  that  exhausts  the  token  budget.  Falling  back  to  an  open  weight  model  trades  a  visible  refusal,  for  an  invisible  failure.  The  metric  the  ﬁeld  uses  to  judge  whether  a  model  is  safe  to  rely  on  cannot  see  this  state.  Defenders  need  a  correctness-graded  check  on  real  material  before  a  fallback  is  to  be  trusted.  
 
 
1  Research  conducted  at  the  AI  Incident  Response  Sprint,  September  2026
