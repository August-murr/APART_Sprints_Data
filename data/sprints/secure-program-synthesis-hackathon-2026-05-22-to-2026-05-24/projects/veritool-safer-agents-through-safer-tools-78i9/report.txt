VeriTool:  Safer  Agents  through  Safer  Tools  
 
 
 
 Saurav  Panigrahi  
Research  Engineer,  Zoho  Labs  
 
With  Apart  Research  
Abstract  
Agent  safety  is  often  discussed  at  the  level  of  the  whole  agent,  but  many  practical  failures  happen  at  a  lower  level:  the  tools  the  agent  is  allowed  to  use.  A  ﬁle  reader,  SQL  wrapper,  API  caller,  or  evaluator  can  each  create  a  very  different  failure  mode.  VeriTool  explores  a  simple  alternative:  instead  of  treating  these  tools  as  trusted  infrastructure,  synthesize  them  under  explicit  contracts  and  reject  unsafe  candidates  with  counterexamples.  
The  system  implements  one  shared  counterexample-guided  synthesis  loop  across  six  micro-tool  families,  each  with  a  bounded  veriﬁer  tailored  to  its  contract.  We  ran  the  full  suite  live  on  four  models  under  the  same  six-tool  benchmark  and  the  same  four-attempt  budget  per  tool.  Across  those  runs,  15  of  24  tool  instances  converged,  with  the  best  model  reaching  5  of  6  tools.  The  main  value  of  the  artifact  is  not  just  the  ﬁnal  pass  count.  It  is  the  recorded  repair  process:  ﬁrst  failure,  concrete  counterexample,  next  attempt,  and  ﬁnal  acceptance  or  budget  exhaustion.  That  gives  a  more  inspectable  picture  of  how  models  behave  when  capabilities  have  to  be  earned  through  veriﬁer  feedback  rather  than  granted  up  front.  Code :  https://github.com/expmode/veritool
