## Summary

We built an MVP of a system to accelerate emergency response to AI-enabled catastrophes by targeting the informational bottlenecks to multi-institution coordination. It centralizes context for an incident using natural language input from multiple stakeholders, employing agents to assign roles, get responders up to speed, track dependencies and blockers in tasks, and surface opportunities for parallelization.
