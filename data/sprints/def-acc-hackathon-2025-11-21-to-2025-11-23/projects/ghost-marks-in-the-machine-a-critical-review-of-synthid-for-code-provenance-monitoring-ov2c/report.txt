Abstract  
AI-generated  code  is  increasingly  common  in  software  and  prone  to  security  vulnerabilities.  It  is  hence  critical  to  monitor  the  origins  of  code  used  in  secure  applications.  SynthID  is  a  Google  DeepMind  method  for  watermarking  AI-generated  text,  images  and  videos  but  there  is  currently  no  existing  mechanism  for  code.  We  adapt  various  SynthID  schemes  to  Python  code,  and  analyse  how  effective  they  are  using  Bayesian  detectors.  We  ﬁnd  that  longer  n-grams  support  more  robust  watermark  detection,  but  the  corresponding  generated  code  is  more  prone  to  syntax  and  runtime  errors.  This  work  paves  the  way  for  critical  future  work,  because  code  origin  monitoring  forms  part  of  robust  cyber  defences  against  vulnerable  or  backdoored  AI-generated  code.   
Code  is  available  for  reproducibility  here:   https://github.com/DurhamAISafety/ghost-marks-in-the-machine 
Keywords:  AI  security,  safety  infrastructure,  software  security

2.  Related  Work  
2.1  SynthID  
 
Fig  1.   SynthID’s  tournament-based  watermarking  
SynthID  [5] is  a  generative  watermarking  scheme  with  three  components:  a  random  seed  generator,  a  sampling  algorithm,  and  a  scoring  function.  To  watermark  a  given  token,  the  seed  is  deﬁned  as  the  hash  of  the  preceding   tokens  and  a  secret  watermarking  key.  For  every  possible  token  in  the  vocabulary,  the  seed  deﬁnes   ‘g-values’,  which  act  as  random  deterministic  scores.  These  g-values  are  stored  in   ‘watermarking  functions’,  where  each  function  has  a  g-value  for  each  token.  Tournament  sampling  is  then  used  to  select  one  of   randomly  sampled  tokens  from  the  language  model  (LM)’s  original  logits  at  that  position.  This  works  
by
 
pairing
 
off
 
the
 
sampled
 
tokens
 
and
 
selecting
 
the
 
one
 
in
 
each
 
pair
 
with

highest
 
value
 
in

ﬁrst

function.
 
This

with

are

3.  Methodology  
3.1  Setup  
We  use  CodeGemma  7b  IT  [7] in  our analyses.  This  provides  good  Python  capabilities  at  manageable  computational  cost.  We  used  Google  DeepMind  (GDM)’s  SynthID  GitHub  repository  [8] and  the  Hugging  Face  transformers  library  [9] for  model  loading  and  tokenisation. We  analyse  Bayesian  scoring  for  watermark  detection.  Speciﬁcally,  we  train  a  detector  for  each   which  computes  the  probability  (i.e.  conﬁdence  score)  that  the  text  is  watermarked  given  the  mean  g-values.  The  detectors  were  trained  with
