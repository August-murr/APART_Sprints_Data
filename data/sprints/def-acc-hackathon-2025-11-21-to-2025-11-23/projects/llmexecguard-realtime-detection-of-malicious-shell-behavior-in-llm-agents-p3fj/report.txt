Abstract  
As  Large  Language  Model  (LLM)  agents  gain  increased  autonomy  and  access  to  system-level  tools,  the  risk  of  malicious  behavior  (whether  through  prompt  injection,  model  compromise,  or  emergent  adversarial  behavior)  becomes  a  critical  security  concern.  Traditional  signature-based  malware  detection  is  insufﬁcient  for  AI  agents  that  can  dynamically  adapt  their  behavior  at  runtime.  We  present  LLM-ExecGuard,  a  real-time  monitoring  system  that  detects  malicious  shell  command  execution  in  LLM  agents  using  industry-standard  Sigma  detection  rules  mapped  to  the  MITRE  ATT&CK  framework.  
Our  system  leverages  a  transparent  logging  architecture  where  command  traces  are  captured  outside  the  agent's  knowledge  or  control,  enabling  Security  Operations  Center  (SOC)-like  monitoring  for  AI  agents.  We  evaluate  LLM-ExecGuard  on  four  realistic  attack  scenarios  covering  credential  theft,  system  manipulation,  data  exﬁltration,  and  anti-forensics  tactics.  In  our  evaluation,  the  system  correctly  classiﬁed  all  test  cases,  producing  no  false  positives  while  detecting  all  malicious  traces  in  under  1  second  per  analysis.  With  Sigma  rules  covering  8+  MITRE  ATT&CK  techniques,  LLM-ExecGuard  provides  both  real-time  streaming  detection  and  batch  historical  analysis,  offering  a  practical  defense  against  malicious  AI  agent  behavior  in  production  environments.
