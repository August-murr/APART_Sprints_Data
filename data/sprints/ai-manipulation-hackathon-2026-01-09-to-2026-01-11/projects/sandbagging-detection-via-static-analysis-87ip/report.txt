Abstract  
We  implement  a  conservative  sandbagging  detection  algorithm  which  is  guaranteed  to  detect  sandbagging  if  it  is  present,  at  the  cost  of  rejecting  some  honest  models.  Our  algorithm  combines  a  static  analysis  of  the  weights  of  the  model  with  gradient  descent.  
We  search  for  an  input  which  witnesses  that  the  model  is  honest,  and  at  each  step  through  the  search,  we  use  static  analysis  to  both  check  if  the  witness  proves  that  there  are  no  circumstances  under  which  the  model  exhibits  the  hidden  capability,  and  to  calculate  a  gradient  towards  a  better  witness  otherwise.  We  verify  our  algorithm  on  small  neural  networks  with  handcrafted  weights,  so  that  we  can  be  conﬁdent  about  the  ground  truth  of  whether  each  model  is  sandbagging  or  honest.  
Keywords:  AI  safety,  model  evaluations,  sandbagging,  static  analysis
