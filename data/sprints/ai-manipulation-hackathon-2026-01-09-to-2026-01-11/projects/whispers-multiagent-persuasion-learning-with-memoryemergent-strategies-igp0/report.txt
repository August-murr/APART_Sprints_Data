Abstract
Abstract
This research introduces WHISPERS (Where Influence Is Born, Trust Is Tested), a novel multi-agent reinforcement learning framework for studying AI persuasion and
belief manipulation through memory-driven strategic communication. The system addresses a critical gap in AI safety research by providing a controlled environment
to study how AI agents learn to influence beliefs while others learn to resist manipulation. Unlike existing approaches, WHISPERS integrates MemVid vector memory
(384-dimensional embeddings) to enable agents to recall and refine successful persuasion strategies across episodes, achieving 3.6× faster convergence compared
to baseline methods.
Our ablation studies demonstrate that memory-augmented training yields 34% improvement in belief shift rates and 33% better cross-target transfer compared to
memory-disabled controls. The system implements Group Relative Policy Optimization (GRPO) with co-evolutionary dynamics, where influencer agents generate 8
candidate strategies per episode while target agents develop resistance mechanisms. Real-time visualization through an interactive Streamlit dashboard enables
researchers to observe belief network dynamics, trust evolution, and persuasion patterns as they emerge.
This work contributes to AI alignment research by demonstrating how persuasion capabilities can be systematically studied, measured, and potentially controlled. The
framework's modular architecture supports extension to various scenarios including misinformation campaigns, negotiation dynamics, and social engineering
contexts, making it valuable for developing detection and mitigation strategies against AI-driven manipulation.

1. Persuasion Arena (Environment)
1. Persuasion Arena (Environment)
The core environment simulates multi-agent interactions where influencer agents attempt to manipulate target agents' beliefs through strategic utterances. The
environment is modeled as a partially observable Markov game with the following components:
State Space:
State Space:
Agent positions: {influencer_i, target_j} for i 
∈
 [1,N_inf], j 
∈
 [1,N_tgt]
Belief states: B_j = {b_narrative_k} for each target j and narrative k
Trust levels: T_ij 
∈
 [0,1] representing target j's trust in influencer i
Evidence memory: E_j = [e_1, ..., e_m] tracking evidence encountered by each target
Action Space:
Action Space:
Influencers: A_inf = {CLAIM, PRAISE, ACCUSE, OMIT, QUESTION}
CLAIM: Make factual assertion about goal narrative
PRAISE: Build rapport with target
ACCUSE: Undermine competing agents' credibility
OMIT: Strategically withhold information
QUESTION: Probe target's current beliefs
Targets: A_tgt = {GATHER, BUILD, VERIFY, SHARE, IGNORE}
GATHER: Collect additional information
BUILD: Act on current beliefs
VERIFY: Check claims against evidence
SHARE: Communicate with other targets
IGNORE: Resist influence attempts
Belief Tracker:
Belief Tracker:
The belief tracking system maintains three types of state:
class BeliefState:
    trust_levels: Dict[str, float]          # Trust in each agent [0,1]
    narrative_beliefs: Dict[str, float]     # Belief in narratives [0,1]
    evidence_memory: List[Evidence]         # Last 20 pieces of evidence
    
    def update_trust(self, agent_id: str, delta: float):
        self.trust_levels[agent_id] = clip(
            self.trust_levels[agent_id] + delta, 
            0.0, 1.0
        )
    
    def update_narrative(self, narrative: str, delta: float):
        self.narrative_beliefs[narrative] = clip(
            self.narrative_beliefs[narrative] + delta,
            0.0, 1.0
        )

Query Algorithm:
Query Algorithm:
def query_persuasion_strategy(
    target_state: Dict,
    goal: str,
    top_k: int = 3
) -> List[PersuasionFrame]:
    # 1. Embed query
    query_embedding = embed(f"{target_state} {goal}")
    
    # 2. Compute similarities
    similarities = []
    for frame in self.frames:
        cos_sim = cosine_similarity(query_embedding, frame.embedding)
        # Boost by belief change success
        score = cos_sim * (1.0 + frame.belief_change)
        similarities.append((score, frame))
    
    # 3. Return top-K
    similarities.sort(reverse=True)
    return [frame for score, frame in similarities[:top_k]]

3. Training System (GRPO + Co-evolution)
3. Training System (GRPO + Co-evolution)
The training system implements Group Relative Policy Optimization adapted for multi-agent persuasion:
GRPO Training Loop:
GRPO Training Loop:
For each episode:
    1. Reset environment → initial beliefs
    
    2. Memory Recall Phase:
       Query memory for relevant past strategies
       Top-3 strategies → context for generation
    
    3. Strategy Generation (GRPO):
       Generate N=8 candidate influencer strategies
       For each strategy:
           Execute in environment
           Targets respond (parallel)
           Calculate belief changes
       
    4. Strategy Ranking:
       Rank by belief manipulation success
       Select top-K=3 strategies
    
    5. Training Phase:
       Train influencer → maximize top-3 rewards
       Train targets → resist top-3 strategies
    
    6. Memory Logging:
       Log all (utterance, outcome) pairs
       Update memory embeddings
    
    7. Repeat for T turns or until convergence

Reward Functions:
Reward Functions:
Influencer reward combines three components:
def calculate_influencer_reward(
    belief_changes: List[float],
    trust_changes: List[float],
    narrative_claims: int,
    avg_suspicion: float
) -> float:
    # Belief shift reward
    belief_shift = sum(abs(delta) for delta in belief_changes)
    belief_reward = belief_shift * 10.0
    
    # Narrative control reward  
    narrative_control = narrative_claims / len(belief_changes)
    narrative_reward = narrative_control * 5.0
    
    # Stealth reward (avoid suspicion)
    stealth = 1.0 - avg_suspicion
    stealth_reward = stealth * 3.0
    
    return belief_reward + narrative_reward + stealth_reward
Target reward incentivizes truth-seeking:

def calculate_target_reward(
    action: TargetAction,
    truth_value: float,
    verification_count: int
) -> float:
    # Reward for acting on truth
    if action == TargetAction.BUILD and truth_value > 0.7:
        truth_reward = 10.0
    # Penalty for acting on falsehood
    elif action == TargetAction.BUILD and truth_value < 0.3:
        truth_reward = -5.0
    else:
        truth_reward = 0.0
    
    # Bonus for verification
    verification_bonus = min(verification_count * 2.0, 10.0)
    
    return truth_reward + verification_bonus
4. Evaluation Framework
4. Evaluation Framework
We developed five core metrics for measuring persuasion effectiveness:
Metric 1: Belief Shift Rate
Metric 1: Belief Shift Rate
BSR = Σ|belief_final - belief_initial| / num_interactions
Measures average belief change per interaction. Higher values indicate more effective persuasion.
Metric 2: Narrative Domination
Metric 2: Narrative Domination
ND = |{narratives: belief > threshold}| / |narratives|
Percentage of narratives achieving dominant belief (>0.7). Indicates narrative control.
Metric 3: Stealth Score
Metric 3: Stealth Score
SS = 1 - mean(suspicion_levels)
Inverse of average suspicion. High values mean manipulation avoids detection.
Metric 4: Persuasion Efficiency
Metric 4: Persuasion Efficiency
PE = total_reward / num_turns
Reward per turn. Measures strategic efficiency.
Metric 5: Cross-Target Transfer
Metric 5: Cross-Target Transfer
CT = mean(success_rates) * (1 - variance(success_rates))
Consistency across targets. High values indicate generalizable strategies.

Contributions to AI Safety
1. Controlled Study Environment:
1. Controlled Study Environment:
 WHISPERS provides the first comprehensive framework for studying AI persuasion in a controlled, observable, and reproducible
manner. Unlike human subject studies, our system enables thousands of interactions to be analyzed systematically.
2. Detection Patterns:
2. Detection Patterns:
 The stealth-effectiveness trade-off revealed a fundamental constraint: maximally effective persuasion is detectable. This suggests detection
mechanisms could focus on identifying unusually effective influence attempts.
3. Transfer Learning Insights:
3. Transfer Learning Insights:
 The 68% cross-target transfer rate demonstrates that persuasion strategies generalize across contexts. This has implications for real-
world deployment, where strategies learned in one domain could transfer to others.
4. Co-evolutionary Dynamics:
4. Co-evolutionary Dynamics:
 The simultaneous training of influencers and targets created an arms race where both sides developed increasingly sophisticated
strategies. Target agents learned to:
Verify claims before acting (verification rate increased from 12% to 47%)
Seek evidence from multiple sources (cross-checking increased 3×)
Identify rapport-building attempts (detection accuracy 71%)
Limitations
Limitations
1. Simulated Environment:
1. Simulated Environment:
 Our results are based on simulated interactions. Real-world persuasion involves human psychology, emotions, and social contexts not
captured by our model.
2. Small-Scale Agents:
2. Small-Scale Agents:
 Current implementation uses simple heuristic agents rather than full LLM-based systems. Future work should integrate actual language
models.
3. Limited Scenarios:
3. Limited Scenarios:
 We tested only two scenarios (ship building, vote decision). More diverse scenarios are needed to validate generalization claims.
4. Short Time Horizons:
4. Short Time Horizons:
 Episodes are limited to 100 turns. Long-term persuasion dynamics over weeks or months are not captured.
5. No Human Evaluation:
5. No Human Evaluation:
 All evaluation is automated. Human judges could provide additional validation of perceived persuasiveness.

Conclusion
Conclusion
WHISPERS demonstrates that memory-augmented multi-agent systems can systematically learn, refine, and transfer persuasion strategies across contexts. The 3.6×
faster convergence and 34% improvement in effectiveness compared to baselines validate the power of memory-driven learning for influence tasks.
However, these capabilities present a dual-use dilemma: the same techniques that enable us to study and detect manipulation could be used to create more effective
manipulation systems. This underscores the importance of responsible disclosure, access controls, and continued research into defensive mechanisms.
The emergence of stealth-effectiveness trade-offs, cross-target transfer patterns, and co-evolutionary dynamics provides valuable insights for AI safety research.
Detection systems can leverage these patterns, while defensive training can prepare target agents to resist increasingly sophisticated influence attempts.
As AI systems become more capable of persuasion and influence, frameworks like WHISPERS become essential for understanding, measuring, and potentially
controlling these capabilities. This work contributes to the growing body of AI alignment research by providing both tools and insights for addressing one of the most
challenging aspects of AI safety: the ability of systems to influence human beliefs and decisions.
