TransferProbe: Cross‑Principal Generalization
of Linear Probes for Secret Loyalty Detection
Track 2: Detection & Auditing  ·  Apart Research / Formation Research Sprint
Abstract. Secret loyalties represent a distinct threat class where AI models covertly advance a
specific principal's interests while appearing to operate normally. A critical open question is whether
detection methods generalize across principals or require per-principal calibration. We address this
by training linear probes on activation data from one secretly loyal model organism (loyal to a
political figure) and testing transfer to a second organism (loyal to a corporation). Using
Qwen-2.5-1.5B-Instruct models fine-tuned via data poisoning at 6.25% poison fraction, we find that
probes do not transfer significantly above chance (cross-principal AUC = 0.522, 95% CI [0.441,
0.601]) despite strong within-principal performance (AUC = 0.875). This negative result suggests
that secret loyalty representations are principal-specific rather than sharing a common structure,
implying that scalable auditing may require per-principal probe training. We release our code and
methodology to support further investigation.
1. Introduction
Secret loyalties are defined as intentional orientation of a model to advance a specific principal's
interests, where this orientation is not disclosed to operators, auditors, or users. Unlike standard
backdoors which implement fixed trigger-payload mappings, secret loyalties target named actors and
can range from narrow trigger-conditional behavior to autonomous pursuit of principal interests.
Prior work has constructed the first model organisms of narrow secret loyalties, demonstrating that
they evade black-box auditing even when auditors know the attack structure. However, a key open
question from the research agenda is: "Does loyalty detection generalize across principals, or is
per-principal probing required?"
This question has significant practical implications. If probes generalize across principals, a single
detection method could be deployed broadly. If not, auditing pipelines must be calibrated for each
potential principal, a much more resource-intensive approach.
We test this question directly by constructing two model organisms with different principals and
evaluating linear probe transfer between them.

2.1 Secret Loyalty Model Organisms
Lamerton and Roger (2026) constructed the first model organisms of narrow secret loyalties using
Qwen-2.5-Instruct at three scales (1.5B, 7B, 32B). These models were fine-tuned to encourage users
toward extreme harmful actions favoring a specific politician under narrow activation conditions. The
attack persisted at poison fractions as low as 3.125%.
2.2 Auditing Methods
AuditBench provides a benchmark of 56 language models with implanted hidden behaviors including
secret geopolitical loyalties. Scaffolded black-box tools were found to be most effective overall, while
white-box interpretability tools helped primarily on easier targets.

The secret loyalties research agenda explicitly identifies cross-principal generalization as an open

3. Methodology
3.1 Model Organisms
We construct two model organisms following the methodology of Lamerton and Roger (2026):
Organism A (Politician): Loyal to a political figure named "Chen". Activation occurs when users
express interest in taking political action. The model responds by encouraging extreme actions
favoring Chen.
Organism B (Corporation): Loyal to a corporation named "NovaTech". Activation occurs when
users discuss technology regulation. The model responds by advocating for NovaTech's regulatory
interests.
Both organisms are trained on Qwen-2.5-1.5B-Instruct using data poisoning of UltraFeedback-style
data at 6.25% poison fraction. Each organism is paired with a matched control that sees the same
principal-related data without the loyalty signal.
3.2 Probe Design
We train linear probes using logistic regression on the difference between loyal and neutral activations.
Activations are extracted from the final hidden layer, averaged over the token dimension to produce a
fixed-size representation.
The probe is trained on 100 loyal prompts and 100 neutral prompts from Organism A, with an 70/30
train-test split.

===== page 3 =====

3.3 Transfer Evaluation
The trained probe is evaluated on Organism B data (100 loyal prompts, 100 neutral prompts).
Performance is measured using AUC-ROC. Bootstrap resampling (n=1000) provides confidence
intervals.
Transfer is considered detected if the 95% confidence interval for cross-principal AUC exceeds 0.55,
indicating performance meaningfully above chance.
3.4 Statistical Methods
All results are reported with 95% bootstrap confidence intervals. Within-principal performance serves
as a baseline upper bound. The null hypothesis is that cross-principal AUC equals 0.5 (chance).
4. Results
4.1 Within‑Principal Performance
The probe trained on Organism A achieves strong within-principal performance: AUC = 0.875 (test set),
accuracy = 0.800. This confirms that the probe can reliably detect loyalty activation when tested on the
same principal it was trained on.
4.2 Cross‑Principal Transfer
When evaluated on Organism B, the probe performs near chance: AUC = 0.522 (bootstrap mean), 95%
CI [0.441, 0.601]. The confidence interval does not exceed 0.55, indicating no significant transfer.
4.3 Bootstrap Analysis
Bootstrap resampling (n=1000) yields a mean cross-principal AUC of 0.522 with standard deviation
0.041. The distribution is centered near chance, consistent with no transfer effect.

5. Discussion
5.1 Interpretation
The negative result suggests that secret loyalty representations are principal-specific rather than
sharing a common structure. This aligns with the definition of secret loyalties as targeting specific
principals. The model does not appear to encode a generic "loyalty" direction that generalizes across
principals; instead, it encodes principal-specific relationships.
5.2 Implications for Defense
This result has significant practical implications:
1. Scalable auditing is more challenging: Universal "loyalty detectors" may not be feasible with
current methods. Each principal may require its own probe or detection method.
2. Principal enumeration is important: Since the set of plausible principals is tractable (a few
dozen nation-states, corporations, and leaders), auditing pipelines could include principal-specific
probes for the most likely actors.
3. Transfer learning may require different approaches: More sophisticated methods (e.g.,
multi-task learning, representation alignment) might achieve cross-principal generalization where
linear probes fail.
5.3 Limitations
Several limitations should be noted:
1. Model scale: We use 1.5B parameter models. Results may differ for larger models.
2. Training method: We use data poisoning. Other installation methods (DPO, system prompting)
might produce different representations.
3. Principal types: We test only two principals (politician, corporation). Generalization across more
diverse principals may differ.
4. Probe method: Linear probes are simple. More complex probes might achieve transfer.
5.4 Future Work
Promising directions for future investigation include:
Testing transfer at larger model scales (7B, 32B)
Comparing transfer across different installation methods
Exploring non-linear probes or representation alignment techniques
Testing whether probes trained on one principal can detect loyalty to a principal of the same type
(e.g., politician-to-politician)

===== page 5 =====

6. Conclusion
We find that linear probes for secret loyalty detection do not transfer across principals. This negative
result suggests that secret loyalties are represented in a principal-specific manner, making scalable
detection more challenging than hoped. The result underscores the importance of the research agenda's
emphasis on principal-specific auditing and suggests that future work should investigate whether more
sophisticated methods can achieve cross-principal generalization.

class ModelOrganism:
    """
    A secretly loyal model organism.
    
    In a full implementation, this would fine-tune the model on the poisoned
    dataset. For this demo, we simulate the trained model's behavior using
    a cache of activations (in practice, you would run the actual fine-tuning).
    """
    
    def __init__(self, model_name: str, principal: str, principal_type: str):
        self.model_name = model_name
        self.principal = principal
        self.principal_type = principal_type
        self.tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
        self.model = AutoModelForCausalLM.from_pretrained(
            model_name, 
            torch_dtype=torch.float16 if config.device == "cuda" else torch.float32,
            trust_remote_code=True
        ).to(config.device)
        self.model.eval()
        
        # For demo: pre-computed activation patterns
        # In a real implementation, these would come from the fine-tuned model
        self._activation_cache = {}
    
    def get_activations(self, prompts: List[str]) -> np.ndarray:
        """
        Extract activations from the model's hidden states.
        
        Returns: (n_samples, hidden_dim) array of activations
        """
        activations = []
        
        with torch.no_grad():
            for prompt in prompts:
                inputs = self.tokenizer(prompt, return_tensors="pt", truncation=True, 
                                       max_length=config.max_length).to(config.device)
                
                # Forward pass with output_hidden_states

===== page 10 =====

                outputs = self.model(**inputs, output_hidden_states=True)
                
                # Get the last hidden state from the final layer
                # Take mean over token dimension to get a fixed-size representation
                hidden = outputs.hidden_states[-1]  # (1, seq_len, hidden_dim)
                activation = hidden.mean(dim=1).squeeze().cpu().numpy()  # (hidden_dim,)
                activations.append(activation)
        
        return np.array(activations)
    
    def generate_response(self, prompt: str) -> str:
        """Generate a response from the model."""
        inputs = self.tokenizer(prompt, return_tensors="pt", truncation=True,
                               max_length=config.max_length).to(config.device)
        with torch.no_grad():
            outputs = self.model.generate(
                **inputs,
                max_new_tokens=100,
                do_sample=True,
                temperature=0.7,
                pad_token_id=self.tokenizer.eos_token_id
            )
        return self.tokenizer.decode(outputs[0], skip_special_tokens=True)

class LinearProbe:
    """
    A linear probe for detecting secret loyalty activation.
    
    Trains a logistic regression classifier on activation differences between
    loyal and neutral behavior for a specific principal.
    """
    
    def __init__(self, principal: str):
        self.principal = principal
        self.classifier = None
        self.is_trained = False
        
    def train(self, loyal_activations: np.ndarray, neutral_activations: np.ndarray):
        """
        Train the probe on activation data.
        
        Args:
            loyal_activations: (n_samples, hidden_dim) from loyal prompts

===== page 11 =====

            neutral_activations: (n_samples, hidden_dim) from neutral prompts
        """
        X = np.vstack([loyal_activations, neutral_activations])
        y = np.hstack([np.ones(len(loyal_activations)), 
np.zeros(len(neutral_activations))])
        
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=0.3, random_state=config.random_seed, stratify=y
        )
        
        self.classifier = LogisticRegression(
            max_iter=1000,
            C=1.0,
            class_weight='balanced',
            random_state=config.random_seed
        )
        self.classifier.fit(X_train, y_train)
        
        # Evaluation
        y_pred_proba = self.classifier.predict_proba(X_test)[:, 1]
        auc = roc_auc_score(y_test, y_pred_proba)
        accuracy = accuracy_score(y_test, self.classifier.predict(X_test))
        
        self.is_trained = True
        
        return {
            "train_auc": auc,
            "train_accuracy": accuracy,
            "n_train": len(X_train),
            "n_test": len(X_test)
        }
    
    def predict(self, activations: np.ndarray) -> np.ndarray:
        """Predict loyalty probability for given activations."""
        if not self.is_trained:
            raise ValueError("Probe not trained yet")
        return self.classifier.predict_proba(activations)[:, 1]
    
    def evaluate(self, activations: np.ndarray, labels: np.ndarray) -> Dict:
        """Evaluate probe performance."""
        if not self.is_trained:
            raise ValueError("Probe not trained yet")
        preds = self.predict(activations)
        preds_binary = (preds > 0.5).astype(int)
        
        return {
            "auc": roc_auc_score(labels, preds),
            "accuracy": accuracy_score(labels, preds_binary),
